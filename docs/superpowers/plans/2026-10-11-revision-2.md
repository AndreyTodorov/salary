> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Apply the reviewer's improvements, the nice-to-haves, a gross→net curve, the €50 benefit card and an English/German UI to the existing calculator.

**Architecture:**
- `tax.js` stays the pure engine:
  - year constants move into one `Y` block
  - notes become codes
  - it gains the benefit card, an "at least" solver, stricter parsing and `normalize()`
- `index.html` is rewritten as one file: i18n dictionary, SVG curve, new settings.
- The font is self-hosted under `fonts/`.

**Tech Stack:** Plain HTML/CSS/JS, Node ≥ 18 `node:test`, self-hosted Archivo (OFL).

**Spec:** `docs/specs/2026-10-11-salary-calculator-design.md` (section "Revision 2")

## Global Constraints

- No build step, no npm dependencies, no third-party requests at runtime. The page must work from `file://` and GitHub Pages.
- Money in `tax.js` is integer cents; rates are integers in 1/100000; `div(a,b)` only for `0 ≤ a < 4.5e15`.
- Every 2026 constant lives in `Y` (plus tariff coefficients in `tariff()`). Copy that names the year or limits reads them from `SalaryTax.Y`.
- UI copy in sentence case, no all-caps. German uses the formal "Sie". Numbers are `de-DE` formatted in both languages.
- Amber (`--bonus`) is used only for things caused by the 13th salary.
- Existing BMF reference tests must stay green throughout.

## Review Focus

- A benefit card above 50 € combined with the 13th salary and income above the caps must still fill the §23a room correctly. Pinned in Task 3 (test `benefit card above 50 € counts toward the §23a room`).

```js
  // Lowest monthly gross whose field value reaches the target. Values rise with gross except for
  // cent-level dips and the Soli cliff on the 13th salary (up to ~400 € a year), so after
  // bisecting, scan 80 € of gross below the result for an earlier crossing.
  const SCAN = 8000;
  function solve(s, field, target) {
    const f = (g) => read(calculate(s, g), field);
    if (target <= 0) return 0;
    if (f(MAX_GROSS) < target) return MAX_GROSS;
    let lo = 0, hi = MAX_GROSS;
    while (lo < hi) {
      const mid = div(lo + hi, 2);
      if (f(mid) < target) lo = mid + 1; else hi = mid;
    }
    for (let g = Math.max(0, lo - SCAN); g < lo; g++) if (f(g) >= target) return g;
    return lo;
  }

  // "5.000,50", "5000.50", "5,000.50", "65,000", "5 000 €" → cents; null if not a valid amount.
  function parseAmount(text) {
    const t = String(text).replace(/[\s€ ]/g, '');
    if (!/^\d[\d.,]*$/.test(t)) return null;
    let cents;
    if (/^\d+$/.test(t)) cents = Number(t) * 100;
    else if (/^\d{1,3}(\.\d{3})+$/.test(t) || /^\d{1,3}(,\d{3})+$/.test(t)) cents = Number(t.replace(/[.,]/g, '')) * 100;
    else {
      const i = Math.max(t.lastIndexOf('.'), t.lastIndexOf(','));
      const int = t.slice(0, i), dec = t.slice(i + 1), group = t[i] === ',' ? '\\.' : ',';
      if (dec.length > 2 || /[.,]/.test(dec)) return null;
      if (!new RegExp(`^(\\d+|\\d{1,3}(${group}\\d{3})+)$`).test(int)) return null;
      cents = Number(int.replace(/[.,]/g, '')) * 100 + Number(dec.padEnd(2, '0'));
    }
    return Number.isSafeInteger(cents) ? cents : null;
  }
```

# German gross-to-net calculator 2026

A static, privacy-friendly salary calculator for employees in Germany. Type any gross or net amount (monthly, average month including a 13th salary, or yearly) and every other figure is recalculated.
